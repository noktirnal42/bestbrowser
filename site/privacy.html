BestBrowser

Privacy

Privacy overview

BestBrowser is built around local browsing context, built-in cleanup tools, and on-device AI support on compatible Macs.

What the app does locally

  • Stores browsing history, bookmarks, workspaces, and watch data locally on your Mac
  • Uses Privacy Shield, tracker blocking, popup stripping, and page cleanup tools inside the app
  • Uses Apple Foundation Models for on-device AI features when available

What it does not require

  • No external AI API keys for the current Foundation Models path
  • No mandatory cloud sync
  • No hosted account system required to browse or save local context

Storage location

BestBrowser initializes its local database under ~/Library/Application Support/com.bestbrowser/.

Important note

This page is a product-level privacy overview, not a formal legal privacy policy. If you plan to distribute BestBrowser beyond direct source or release sharing, add a dedicated legal policy before treating this site as a public product policy surface.
